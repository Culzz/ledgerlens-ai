# Typefaces

These are the three typefaces this project ships, each under the SIL Open Font
License 1.1, which permits use, redistribution and bundling with software. The
files here are the subsets of each family named below. The license text is in
`LICENSE-OFL.txt` beside this file.

| Typeface | Where it is used | Authors, from the specimen metadata |
| --- | --- | --- |
| Instrument Sans | interface type | Copyright 2021 The Instrument Sans Project Authors |
| Newsreader | headings, figures, prose | Copyright 2020 The Newsreader Project Authors |
| Spline Sans Mono | tables, code, numbers | Copyright 2022 The Spline Sans Mono Project Authors |

All three are distributed from Google Fonts, which hosts the live specimens and
current license copies.
